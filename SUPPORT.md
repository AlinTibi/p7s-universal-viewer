# Support

For usage questions: support@almarfeld.com. For reproducible bugs, open an issue with Windows version, application version and a synthetic sample. Keep personal documents and local paths out of public reports.

Detached signatures require the exact original file. An untrusted self-signed certificate can still have valid cryptographic integrity. Missing WebView2 affects PDF preview only; extraction remains available. Archives and Office files are extracted without decompression or rendering.
